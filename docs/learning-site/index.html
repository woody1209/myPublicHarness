1. 控制金字塔 架构

电机控制软件是分层的，每层有独立的时间尺度。下层时序不确定，上层再精巧的算法也会失稳。

层时间尺度职责本项目状态
速度/位置环10 ms ~ 100 ms 外环 PI，给定速度/位置，输出 Iq 电流参考 未覆盖
电流环 PI (Id/Iq)100 µs ~ 1 ms 解耦控制，输出电压矢量 u_d/u_q 未覆盖（需真实相电流）
SVPWM + 开环电角度10 µs ~ 100 µs 电压矢量 → 三相占空比；电角度积分器 已实证（spec 0002）
ePWM / ADC / CMPSS / 启动100 ns ~ 10 µs 硬件时基、采样触发、保护 trip、时钟门控 已实证
学习策略：从最底层往上盖。先把 10 kHz 载波 + 1 µs 死区 + 载波谷底采样这套 确定性时基做扎实，电流环整定才有意义。

2. SVPWM 数学 — min-max 定心 算法

SVPWM 把电压空间矢量 (α, β) 转成三相占空比。本项目采用 min-max 定心（零序注入），保证线电压不变、且占空比居中。

2.1 Clarke 逆变换

α = mag · cos(θ) / 1000
β = mag · sin(θ) / 1000
ta = α
tb = −0.5·α + 0.866·β
tc = −0.5·α − 0.866·β

2.2 min-max 定心（零序偏移）

off = min(ta, tb, tc)
da = ta − off    db = tb − off    dc = tc − off

定心只改共模，不改差模——这是线电压不变性的来源：

da − db = ta − tb     db − dc = tb − tc

2.3 过调制守卫

当 max − min > 1000‰ 时，三相整体等比缩放，保证可表达（不追求过调制能力）。

if (max − min > 1000) { da,db,dc *= 1000/(max−min) }

2.4 零矢量

mag = 0 时输出三相 500 / 500 / 500（占空比 50%，零电压矢量）。

2.5 四分之一波查表

sin/cos 用 901 项定点表（0..90°，每 0.1° 一项，int16 千分比，共 1802 B .const）， 全波靠象限反射：cos(x) = sin(x+90°)。无浮点、无运行时 math 库。

验收：主机单测 test_svpwm.c 断言线电压不变性、定心范围 0..1000、 过调制守卫、非法入参负码。参考 harness/tests/host/test/test_svpwm.c。

3. 开环电角度发生器 算法

没有编码器时，用电角度积分器模拟转子位置。分辨率 0.1°（0..3599）， 速率单位 0.01 Hz。核心是精确有理累加（64 位余数），保证任意 tick 拆分序列终点一致。

accum += rate_x100 × tick_us × 3600
steps = accum / 100000000
accum %= 100000000
angle_x10 = (angle_x10 + steps) mod 3600
参数默认说明
电频率 rate_x100500（= 5.00 Hz）上限 50000（500 Hz）
分辨率0.1°angle_x10 范围 0..3599
结合律—相同总时长、不同 tick 拆分 → 终点一致（主机单测覆盖）
边界—tick_us=0 或空指针 → 原样返回，不修改状态

4. 死区与互补极性 硬件

三相半桥的上下桥不能同时导通（直通短路）。死区在互补边沿间插入延时。

DBCTL.POLSEL = 2   →   OUTB = ¬OUTA（Active High Complementary）
RED = FED = 120 TBCLK cycles = 1 µs @ 120 MHz
计数：EPWM_DB_COUNTER_CLOCK_FULL_CYCLE

4.1 动作序列（AQ）

ZRO → SET (HIGH)
UP_CMPA → CLEAR (LOW)
DOWN_CMPA → SET (HIGH)
占空比 = CMPA / PRD

中心对齐 up-down 计数（载波从 0 升到 PRD 再降回 0）。 频率 = SYSCLK / (2·PRD) = 120MHz / (2×6000) = 10 kHz。

物理陷阱：占空比 = PRD = 1000 时，某相 A/B 整周期都是低 （两端谷 + 死区覆盖全周期）。瞬时读 GPIO 全零是正常波形，不是"调制未恢复"。

5. ADC 采样时序 — SOCA 触发链 硬件

电流采样要避开开关噪声，所以在载波谷底（TBCTR = PRD）触发。 触发链是双向的——ADC 侧和 ePWM 侧都要使能。

ADC 侧：SOC0 ← ADC_TRIGGER_EPWM1_SOCA, 通道 A2 (ADC_CH_ADCIN2)
ePWM 侧：EPWM_setADCTriggerSource(EPWM1, SOC_A, TBCTR_PERIOD)
         + EPWM_enableADCTrigger(EPWM1, SOC_A)
         + EPWM_setADCTriggerEventPrescale(EPWM1, SOC_A, 1) ← SOCAPRD=1 必修
静默失效：只配 ADC 侧触发源而不开 ePWM SOCA 输出，或不设 SOCAPRD，SOC 永远不触发。 表现为轮询永远超时、adc=0xFFFF 占位。

5.1 ADCINTFLG 的门（INT1E）

ADC_setInterruptSource(ADCA, INT1, SOC0)
ADC_enableInterrupt(ADCA, INT1) ← INT1E，缺它则 ADCINTFLG 永不置位

F28003x 的 ADCINTFLG 位只在 INT1E=1 时才会置起。缺它时转换照常完成 （RESULT0 更新）但标志永不置位，任何 EOC 轮询必然超时。INT1E 不是 PIE 中断使能 （本固件从不 EINT、IER 保持 0），脉冲只落在 PIE IFR，无向量风险。

6. 过流保护链 — CMPSS→XBAR→TZ 安全

这条链是纯硬件的，不依赖软件响应。即使固件卡死，功率桥也不会在故障下继续收到驱动信号。

CMPSS1 正端 = CMPIN1P（与 A2 共脚，CMPHPMUX 复位值 0 已选中）
CMPSS1 负端 = 内部 DAC（shadow 模式，SWLOADSEL=0 = SYSCLK 自动加载）
            DAC 上电默认 4095（最大阈值，浮置噪声不误触发）

XBAR TRIP4 ← CMPSS1_CTRIPH (mux00)
            → ePWM1/2/3 DCBH
            → DCBEVT1 (EPWM_TZ_EVENT_DCXH_HIGH)
            → TZA/TZB = LOW（六路 PWM 全关）

一次性锁存：不清源不恢复，须软件显式清 TZ

6.1 自检双向探测契约

上电自检用 COMPSTS 双向探测验证链路，不触发 Trip：

DAC 设置期望 COMPSTS含义
实测 − 5121（跳断）CMPIN1P 高于参考 → 比较器跳断
满量程 40950（免跳）物理上界，规避 A2 悬空噪声误判
API 语义陷阱：board_cmpss_wait_status(expect) 返回的是 "状态是否匹配 expect"的布尔，不是状态值。probe 判定用 hi_ok && lo_ok；打印行的 hi=/lo= 才是比较器实际状态。

6.2 故障恢复

TZ 锁存后打印 FAULT: tz-latched、停角度推进、LED4 慢闪。 dwell 5 秒且比较器回低于参考后，软件清 TZ 并打印 tz: cleared。

7. MCU 启动顺序 硬件

这是硬顺序，顺序错了会"启动几毫秒即死，无日志无灯"。

.TI.ramfunc 重定位 (memcpy LOAD→RUN)
    → 禁看门狗
    → PIE init
    → 时钟 (SysCtl_setClock)
    → 外设时钟门控 (SysCtl_enablePeripheral)
    → 自检 → superloop
根因：driverlib SysCtl_delay() 编入 .TI.ramfunc （LOAD=FLASH_BANK0_SEC1 / RUN=RAMLS0 0x8000），_c_int00 不做段拷贝。 不先 memcpy 就调 SysCtl_setClock → 跳空 RAM 执行 0x0000 → ITRAP → PIE 未初始化时向量取自 boot ROM → 看门狗复位。

判读口诀：PC 停在 board_clock_init 且 RESC=0 → 先查 ramfunc 重定位。

8. C28x 字地址模型 硬件

C28x 是 16 位字寻址——一切地址/长度都是字，不是字节。这是本仓库第一条硬事实（ADR 0002）。

概念值
sizeof(uint32_t)2 字（不是 4 字节）
CHAR_BIT16（不是 8）
*+XARn[N] 位移N 字（不是 N 字节）
memory.readWord()只返回 1 个 16 位字
32 位寄存器要读两个字拼接
map 文件 size 列字（led_hw_channels 16B → size 0x08=8 字）

8.1 ePWM 寄存器对（关键）

CMPA:CMPAHR   @字 0x6A : 0x6B   → 有效占空比在高字 0x6B
TBPRD:TBPRDHR @字 0x62 : 0x63   → 有效周期在高字 0x63

driverlib EPWM_setCounterCompareValue 写 HWREGH(base + EPWM_O_CMPA + 1)
假 FAIL 根因：HIL 读 0x6A 得到的是 CMPAHR（恒 0），误判"CMPA 不变"。 必须读高字 0x6B 才是有效占空比。

8.2 GPIO 字地址表

寄存器字地址用途
GpioCtrlRegs0x7C00GPAMUX1=0x7C06 / GPADIR=0x7C0A / GPAPUD=0x7C0C
GpioDataRegs0x7F00GPADAT=0x7F00（32b）/ GPASET=0x7F02 / GPACLEAR=0x7F04
GpioDataReadRegs0x7F80GPADAT_R=0x7F80（32b），LED 位在高字 0x7F01

9. 真机教训 — 5 条时序因果 故障树

每条都对应一次真机假 FAIL，根因都出在时序/语义/位宽，不是算法。

现象根因教训
ADC 轮询必超时，adc=0xFFFF INT1E=0 时 ADCINTFLG 永不置位 外设"在跑"≠"状态可读"，标志位有自己的门
SOC 永不触发 SOCAPRD 未配（SOCAPRD2=0） 触发链双向，任一端未使能即断链
cmpss: lo=1 假 FAIL wait_status(expect) 误当状态值用 API 语义 > API 名字，契约必须写进 spec
"PWM 未恢复"假 FAIL 占空比=PRD 的相整周期为低，瞬时读全零 瞬时采样不能证明动态过程，要找"正在变化"的证据
改代码跑的是旧镜像 gmake 同分钟粒度时间戳不触发重编 收口前 clean + 全量 rebuild（ADR 0007）
检验你是否掌握：能解释为什么 HIL 要读 0x6B 不读 0x6A，且能手算 motor: ang=... a=... b=... c=... 三相占空比是否自洽 （线电压不变性 da − db = ta − tb）。
