1. MCU 启动顺序时序 硬顺序

顺序错了会"启动几毫秒即死，无日志无灯"。点击每一步查看寄存器动作。

1.TI.ramfunc 重定位

memcpy LOAD→RUN (FLASH_BANK0_SEC1 → RAMLS0 0x8000)。_c_int00 不做段拷贝。

memcpy(&ramfuncs_loadstart, &ramfuncs_loadsize, &ramfuncs_runstart);

2禁看门狗

WDCR.WDDIS=1。否则 ITRAP 后 boot ROM handler 使能看门狗复位。

DisableDog();  // WDCR = 0x0068

3PIE init

PIECTRL.ENPIE=1，向量表映射到 PIE RAM。本固件 IER 保持 0（无中断驱动）。

InitPieCtrl(); InitPieVectTable();

4时钟 (SysCtl_setClock)

PLL 配 120 MHz SYSCLK。必须在 ramfunc 之后——SysCtl_delay 编入 ramfunc。

SysCtl_setClock(PLL_ENABLE | ...);  // 120 MHz

5外设时钟门控

PCLKCRn 复位后全关，写被静默丢弃。ePWM1/2/3 + ADCA + SCIA + CMPSS1。

SysCtl_enablePeripheral(SYSCTL_PERIPH_CLK_EPWM1..3);
SysCtl_enablePeripheral(SYSCTL_PERIPH_CLK_SCIA);

6自检 → superloop

pwm 回读 → CMPSS 双向探测 → 武装 TZ → 纯逻辑参考序列 → 进主循环。

if (!self_test_run()) { fail_safe(); }
for (;;) { motor_tick(); }
根因（ADR 0003）：.TI.ramfunc 里 SysCtl_delay() 编译进 RAM 段（LOAD=FLASH_BANK0_SEC1 / RUN=RAMLS0 0x8000），_c_int00 不做段拷贝。 不先 memcpy 就调 SysCtl_setClock → 跳空 RAM 执行 0x0000 → ITRAP → PIE 未初始化时向量取自 boot ROM → 看门狗复位。 判读口诀：PC 停在 board_clock_init 且 RESC=0 → 先查 ramfunc。

4. 外设总线时序 硬件

三条独立时序链：ePWM 载波、ADC 触发、CMPSS 保护。它们通过 XBAR 硬连线。

ePWM 载波 TBCTR SOCA 触发脉冲 ADC 转换 (SOC0) CMPSS 比较器 TZ trip (DCBEVT1)
链路触发源时序关键寄存器
ePWM 载波 TBCLK = SYSCLK = 120 MHz 10 kHz 周期 (100 µs) TBPRD=6000, CTRMODE=up-down
SOCA → ADC TBCTR = PRD (载波谷底) 每周期 1 次 ETPS.SOCAPRD=1, SOCAPRD2=1
CMPSS 比较 异步（连续） ns 级响应 COMPSTS, DACHVALS
CMPSS → TZ XBAR TRIP4 → DCBH 硬件直通 TZSEL.DCBEVT1, TZFLG bit5
TZ 关 PWM DCBEVT1 事件 一次性锁存 TZA/TZB = LOW
为什么在谷底采样：开关噪声在载波峰/谷附近最严重，但谷底时所有桥臂占空比最稳定， 是电流采样窗口。SOCAPRD=1 保证"第一个事件就触发"（不是每 N 个）。

5. DSS 调试时序 验证

HIL (Hardware-in-the-Loop) 用 DSS 脚本读寄存器、强制故障、验证恢复。时序很关键。

阶段动作时序陷阱
H1 JTAG 连接 halt → 读 Device ID cJTAG 2-pin，必须用 LaunchPad ccxml
H2 烧录 loadProgram() → runAsynch 需 --args=0x200 定义 __c_args__（ADR 0004）
H3 自检验证 halt → 读 g_self_test_code halt 后立即读外设报 Error 0x20000（时钟门/未 init）
H5 强制越限 写 CMPSS DAC=0 → 读 TZFLG CMPA 要读 0x6B 不读 0x6A
H5b 恢复判定 清 TZ → 等 CMPA 变化 1-tick 竞态：先等 tzAllClear 再判 CMPA
H6 独立运行 PC=code_start, runAsynch 探针在线时 reset 不交接 flash（ADR 0006）
halt 后读外设报 Error 0x20000：时钟门/未 init。需 runAsynch 让固件跑完再读。 HIL 脚本按此顺序。

5.1 H5 判据源码片段

// Prove modulation RESUMED after the latch clear. Do NOT use an
// instantaneous GPADAT_R read for this: in this centre-aligned up-down
// design a phase sitting at cmpa = PRD = 1000 keeps BOTH its A/B pins
// low for the entire carrier cycle.
function readCmpa3() {
    return [readWordRetry(EPWM_BASES[0] + O_CMPA),   // O_CMPA = 0x6B
            readWordRetry(EPWM_BASES[1] + O_CMPA),
            readWordRetry(EPWM_BASES[2] + O_CMPA)];
}
var resumeBase = readCmpa3();
// ... wait 1.5s, compare — any change = resumed

6. 故障时序因果链 故障树

5 条真机教训，每条都对应一次假 FAIL。点击展开因果链。

① ADC 轮询必超时

adc=0xFFFF

因果链：INT1E=0 → ADCINTFLG 永不置位 → 轮询超时 → 占位 0xFFFF

教训：外设"在跑"≠"状态可读"，标志位有自己的门。

② SOC 永不触发

adc 读数不更新

因果链：SOCAPRD 未配 → SOCAPRD2=0 → 即使 SOCAEN=1 也不触发

教训：触发链双向，任一端未使能即断链。

③ cmpss: lo=1 假 FAIL

自检 FAIL

因果链：wait_status(expect) 返回匹配布尔被误当状态值用

教训：API 语义 > API 名字，契约必须写进 spec。

④ "PWM 未恢复"假 FAIL

H5 FAIL

因果链：占空比=PRD 相整周期为低 → 瞬时 GPIO 读全零 → 误判未恢复

教训：瞬时采样不能证明动态过程，要找"正在变化"的证据。

⑤ 改代码跑旧镜像

时间戳

因果链：gmake 同分钟粒度时间戳 → 不触发重编 → 跑的是旧 .out

教训：收口前 clean + 全量 rebuild（ADR 0007）。

⑥ 启动几毫秒即死

无日志无灯

因果链：ramfunc 未重定位 → 跳空 RAM → ITRAP → 看门狗复位

教训：硬顺序不可调换（ADR 0003）。
