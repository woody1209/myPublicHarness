# 30 · 编码与单元测试规范

## C 编码规范（AI 产出强制）

1. **C11**；禁止 VLA、禁深层宏嵌套；`{}` 必须成对写全。
2. .c/.h 头部标准头注释（文件名、描述、许可证来源：TI driverlib 采用 BSD-3 风格）。
3. 命名：模块 `module_verb_noun`；类型 `module_suffix_t`；宏 `MODULE_NAME`；
   只在本文件可见的一律 `static`。
4. 返回码：布尔/状态用显式 `bool` 或 `typedef enum`（错误分支必须处理后返回，
   禁止"记录后继续假装成功"）。
5. 断言：不可恢复错误经 `ESTOP0`（Debug 下停住）+ 走 fail-safe 指示灯形态，禁止静默继续。
6. 内存：禁止为固定工作负载使用 malloc；本工程无 RTOS 时为事件/轮询驱动。
7. 中断：ISR 最小化（置标志位），处理放主循环；本参考工程暂用 CPUTimer 轮询节拍，
   转中断时需同步更新 design 与 docs。
8. **引脚/时钟/外设参数只来自 `board_pins.h` / `board_clock.c` / driverlib**，
   禁止在业务代码里散落硬编码寄存器值或裸引脚号。
9. 日志经 `sci_log` + `fmt`；禁止裸 `sprintf`。
10. 头文件自包含：每个 .h 可独立编译；包含卫队 `#ifndef <PROJECT>_<FILE>_H`。

## C28x 字地址模型（AI 产出强制，2026-10-17 实证）

C28x 是 **16 位字寻址**架构，与本机常见的字节寻址（ARM/Cortex）直觉完全不同，
地址模型错误会制造假象（详见 `harness/docs/adr/0002-C28x字地址模型与GPIO实证.md`）：

1. **一切地址/长度都是 16 位字**：编译器常量、链接器 `.cmd` 的 `origin/length`、
   map 文件地址**与 size 列**、反汇编操作数、DSS `readWord`，单位全部是字。
   `sizeof(uint32_t) == 2`（字），`CHAR_BIT == 16`。
2. **`*+XARn[N]` 的位移 N 是字**，不是字节。`readWord()` 一次只返回 1 个字；
   读 32 位外设寄存器（如 GPADAT）必须读两个字再拼接（低字 + 高字）。
3. **多字外设寄存器的 LED/高位场落在高字**：GPIO20 = 字地址 0x7F01 的 bit4，
   GPIO22 = 字地址 0x7F01 的 bit6。只读低字 0x7F00 会得到"全灭"的假象。
4. **不得据此怀疑 driverlib**：driverlib 的结构体偏移与设备头
   （`f28003x_gpio.h` 等）经反汇编逐一核对一致，寻址无罪；
   任何"地址对不上"的怀疑先用反汇编 + map 对账，再下结论。
5. **HIL/脚本侧同责**：测试脚本（`hil_test.js` 等）计算外设地址时
   必须显式按字寻址，并在注释中写明地址模型依据。
6. **C28x 没有 8 位类型**：`char` = 16 位（`CHAR_BIT == 16`），`stdint.h` 不提供
   `uint8_t`/`int8_t`；字节级字段、协议缓冲一律 `uint16_t`。禁止书写依赖
   "`sizeof(char)==1` 字节语义"的代码（跨内核复用前先过这一条）。
7. **driverlib DEBUG 断言必须配 `__error__`**：`--define=DEBUG` 下 ASSERT 失败跳转
   `__error__`，应用必须提供实现（见参考工程 `source/board_error.c`：`ESTOP0` 停住），
   否则要到链接期才暴露。
8. **启动顺序是硬约束**：`main()` 首动作必须是 `.TI.ramfunc` 重定位 +
   `board_ramfunc_ready()` 校验，其后才允许任何 `SysCtl_*`/延时调用；随后
   禁看门狗 → PIE 初始化 → 时钟 → 外设。完整理由与证据见
   `40-烧录与调试手册.md`"固件启动顺序"节与 ADR 0003，参考工程照抄 `main.c`。

## 单元测试规范

- 框架：Unity（CMake FetchContent 自动获取，离线可指向本地克隆）。
- 目录：`harness/tests/host/test/test_<module>.c`；模块注册进 `CMakeLists.txt`。
- 每个纯逻辑模块：正常路径 + 边界（空/满/越界）+ 参考序列三类用例齐备。
- 纯逻辑模块的「参考向量」必须由主机侧单测与**目标侧上电自检**双重使用：
  单测里有 `LED_PATTERN_*` / `U8FMT_*` 常量，目标代码编译期引用同一组常量。
- 主机侧测试**无法**覆盖硬件时序；时序/极性/外设交互进 `harness/tests/on-target/README.md`
  的上板自检清单。
